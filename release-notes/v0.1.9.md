# JumpServer Desktop v0.1.9

本次更新统一 Windows、Linux 与 macOS 的顶部窗口布局，修复 Windows／Linux 仍显示独立系统标题栏的问题。

## 跨平台标题栏

- Windows／Linux 隐藏独立系统标题栏，将 Electron 原生最小化、最大化／还原、关闭按钮与应用标签栏放在同一行；macOS 保留现有红黄绿按钮和布局。
- 窗口按钮区域的背景和图标配色跟随应用主题；选择“跟随系统”时也会随系统深浅色切换。
- 按系统报告的窗口按钮位置预留空间，兼容 Linux 左侧或两侧按钮布局，避免标签和工具按钮被遮挡；窄窗口下保留拖动空白区，多标签可横向滚动。
- 加载中和初始化失败时也保留顶部拖动区域。关闭窗口继续经过未保存编辑、活动连接和传输任务的原有确认流程。
- Windows／Linux 自动隐藏应用菜单栏，按 `Alt` 可显示菜单。

## 验证

- 本地 TypeScript 检查与应用构建通过。
- 已实跑 macOS 应用，检查原有顶部布局和新建标签交互；使用 Electron 原生覆盖层验证窗口化、全屏和退出全屏后的安全区域及拖动样式。
- Windows／Linux 渲染界面采用浏览器模拟验证，覆盖按钮左侧、右侧及两侧占位，1024 像素窄窗口、多标签与更新入口并存、主题切换，以及初始化失败后的重试恢复。
- 本地未将 Windows／Linux 真机上的原生按钮、窗口吸附或不同窗口管理器交互列为验证结果。
- 正式安装包由 GitHub Actions 在三平台完成检查、构建和打包启动冒烟验证后发布，附带更新元数据、`SHA256SUMS` 和 `release-manifest.json`。

## 下载与更新

- **Windows x64**：NSIS `.exe` 安装包，支持应用内更新。
- **Linux x64**：AppImage 支持应用内更新；`.deb` 请手动下载安装。
- **macOS Intel / Apple Silicon**：选择对应的 x64／arm64 `.dmg` 手动下载安装；macOS 不自动下载或安装更新。
